This zip contains the directory GRAF that has various math class utilities
all my programs use support programs.  All these files should be stored in
HOME directry

NOFORMAT can store and recall user set display options. This can also call 
FORMOPT to set said properties.  

In the GRAF directory PWYZ a piecewise program. It's dynamic making its own 
variables to store equations and upper and lower bounds for each equation.
The only time it creates a new storage variable is when the maximum number
of the equations was exceeded from all previous times. 

PCALC is a pre-Calc approximation tool graphing rectangles and integral with 
with results on stack after optional graph. Type of approximation number of 
intervals and error amount are shown as well as the labeled approximation. 

FoG is a composite function utility 

QUADSOLVR is a quadratic grapher and analysis with display of graph optional 
using only A B and C the graph is self-aligning and roots vertices and equation 
are put on the stack afterwards 

ROTOR(ROOTER) uses the calcuator own PROOT function but it is self centereing 
when graphing and all roots are put on the stack along with the EQ.
