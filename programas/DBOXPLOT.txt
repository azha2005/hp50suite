\<<
  @ DBOXPLOT - caja, bigotes, outliers, eje y puntos individuales.
  @ Tres capas: DBOXPLOTC calcula los doce numeros, DBOXPLOTG dibuja, y
  @ este objeto pone el formulario, el PICTURE y las cajas. PICTURE es
  @ interactivo, asi que queda aca: de otro modo el harness no puede
  @ probar el grafico.
  @ Los cuartiles son por INDICE; para el metodo interpolado de catedra
  @ (Lp = (p/100)*(n+1)) esta DPCTIL, y pueden dar valores distintos.
  @ Deja los cinco numeros en la pila.
  "Box Plot Univariado"
  { { "Datos:" "Vector [x] o Lista {x}" } }
  { } { } { }
  INFORM
  IF THEN
    1 GET \-> DATA0
    \<<
      DATA0 DBOXPLOTC \-> RES
      \<<
        DATA0 RES DBOXPLOTG
        PICT PICTURE
        "Min: " RES 2 GET \->STR + 10 CHR +
        "Q1: " + RES 3 GET \->STR +
        MSGBOX
        "Med: " RES 4 GET \->STR + 10 CHR +
        "Q3: " + RES 5 GET \->STR +
        MSGBOX
        "Max: " RES 6 GET \->STR + 10 CHR +
        "RIC: " + RES 7 GET \->STR +
        MSGBOX
        "Outliers:" 10 CHR +
        RES 12 GET \->STR +
        MSGBOX
        RES 2 GET RES 3 GET RES 4 GET RES 5 GET RES 6 GET 5 \->LIST
      \>>
    \>>
  END
\>>
