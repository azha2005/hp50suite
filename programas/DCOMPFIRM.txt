%%HP: T(3)A(R)F(.);
\<<
  @ DCOMPFIRM - empresa competitiva, con grafico CMg/CVMe/P.
  @ Tres capas: DCOMPFIRMC calcula { Q PROFIT CIERRA }, DCOMPFIRMG
  @ dibuja, y este objeto pone el formulario, el PICTURE y las cajas.
  @ PICTURE es interactivo, asi que queda aca: de otro modo el harness
  @ no puede probar el grafico.
  "Empresa Competitiva: CT=CF+b*q+c*q^2"
  {
    { "CF (Costo Fijo):" "0" 0 }
    { "b (Costo Marg. Base):" "0" 0 }
    { "c (Coef. Cuadratico):" "0" 0 }
    { "P (Precio de Mercado):" "0" 0 }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP \-> CF B C P
    \<<
      CF B C P DCOMPFIRMC \-> RES
      \<<
        CF B C P RES DCOMPFIRMG
        PICT PICTURE
        "Q*: " RES 1 GET \->STR + 10 CHR +
        "Beneficio: " + RES 2 GET \->STR +
        MSGBOX
        @ La semilla NO lleva + adelante: el MSGBOX de arriba ya consumio
        @ el string y la pila quedo vacia, asi que el + no tendria con que
        @ concatenar (CLAUDE.md 2.4). Estaba mal desde antes.
        IF RES 3 GET 1 == THEN
          "La empresa CIERRA en el corto" 10 CHR +
          "plazo (P menor al CMg minimo)." +
          MSGBOX
        ELSE
          "La empresa sigue produciendo" 10 CHR +
          "en el corto plazo." +
          MSGBOX
        END
      \>>
    \>>
  END
\>>
