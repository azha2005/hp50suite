  SIGFIG
  \<<
    @ Redondea un valor a N cifras significativas (no decimales
    @ fijos). Uso: valor N SIGFIG -> valor redondeado.
    @ Ejemplo: 0.000058013220973 4 SIGFIG -> 0.00005801
    @ IMPORTANTE: guardar esto en HOME (no dentro de una subcarpeta)
    @ para que otros programas (DOLS, etc.) lo puedan llamar por
    @ nombre sin importar en que subcarpeta esten ellos.
    \-> V N
    \<<
      IF V 0 == THEN
        0
      ELSE
        V ABS LOG FLOOR \-> M
        \<<
          N 1 - M - \-> EXPN
          \<<
            10 EXPN ^ \-> ESCALA
            \<<
              V ESCALA * 0 RND ESCALA / \->NUM
            \>>
          \>>
        \>>
      END

  DMODAC
  \<<
    @ DMODAC - nucleo de DMODA. Moda(s) y su frecuencia.
    @ Uso:  Datos DMODAC
    @ Deja: n1 = { MODES MAXFREQ }
    @         Si MAXFREQ es 1 no hay moda: todos los valores son distintos.
    @ Sin INFORM ni MSGBOX a proposito: la interfaz esta en DMODA.
    IF DUP TYPE 3 == OVER TYPE 29 == OR THEN OBJ\-> 1 GET \->LIST END
    SORT
    \-> L
    \<<
      L SIZE \-> N
      \<<
        @ MODES y MAXFREQ son globales (bare STO, se purgan al final).
        @ CURVAL es local: se actualiza con 'CURVAL' STO dentro del mismo
        @ scope y NO entra en el PURGE.
        { } 'MODES' STO
        0 'MAXFREQ' STO
        L 1 GET \-> CURVAL
        \<<
          1 'CURFREQ' STO
          @ El IF protege al FOR de quedar con inicio > fin: con un solo
          @ dato, 2 N FOR EJECUTA UNA VEZ igual (medido en
          @ harness/casos-ruf4.txt; CLAUDE.md 2.7 afirmaba lo contrario) y
          @ el cuerpo pedia L 2 GET, fuera de rango. La racha unica la
          @ cierra igual el bloque de abajo, que corre siempre.
          IF N 1 >
          THEN
          2 N FOR i
            L i GET \-> V
            \<<
              IF V CURVAL == THEN
                CURFREQ 1 + 'CURFREQ' STO
              ELSE
                @ cerrar la racha del valor anterior
                IF CURFREQ MAXFREQ > THEN
                  CURVAL 1 \->LIST 'MODES' STO
                  CURFREQ 'MAXFREQ' STO
                ELSE
                  IF CURFREQ MAXFREQ == THEN
                    MODES CURVAL + 'MODES' STO
                  END
                END
                V 'CURVAL' STO
                1 'CURFREQ' STO
              END
            \>>
          NEXT
          END
          @ el FOR no cierra la ULTIMA racha -- se repite aca
          IF CURFREQ MAXFREQ > THEN
            CURVAL 1 \->LIST 'MODES' STO
            CURFREQ 'MAXFREQ' STO
          ELSE
            IF CURFREQ MAXFREQ == THEN
              MODES CURVAL + 'MODES' STO
            END
          END
          MODES MAXFREQ 2 \->LIST
          { MODES MAXFREQ CURFREQ } PURGE
        \>>
      \>>
    \>>

  DFRECTABLAC
  \<<
    @ DFRECTABLAC - nucleo de DFRECTABLA. Tabla de frecuencias.
    @ Uso:  Datos K H Inicio DFRECTABLAC     (K/H/Inicio en 0 = automatico)
    @ Deja: n1 = { K H START FREQ MAT }
    @         FREQ = vector de frecuencias absolutas por clase,
    @         MAT  = matriz K x 6: Inicio, Fin, Abs, Acum.Abs, %, Acum.%
    @ Con K=0 usa Sturges: K = 1 + 3.322*log(N), redondeado.
    @ Sin INFORM ni MSGBOX a proposito: la interfaz esta en DFRECTABLA.
    @
    @ El bucle de filas deja los 6 valores de cada fila en la pila sin
    @ consumirlos: ahi se acumulan las K*6 celdas hasta el \->ARRY final.
    @ Por eso este nucleo NO lleva guardian de profundidad (CLAUDE.md
    @ 2.11): la acumulacion en la pila es intencional, no basura.
    \-> DATA0 KWANT HWANT SWANT
    \<<
      DATA0
      IF DUP TYPE 3 == OVER TYPE 29 == OR THEN OBJ\-> 1 GET \->LIST END
      SORT
      \-> L
      \<<
        L SIZE \-> N
        \<<
          L 1 GET \-> XMIN
          \<<
            L N GET \-> XMAX
            \<<
              IF KWANT 0 == THEN
                1 3.322 N LOG * + 0 RND
              ELSE
                KWANT
              END
              \->NUM \-> K
              \<<
                IF HWANT 0 == THEN
                  IF XMAX XMIN == THEN 1 ELSE XMAX XMIN - K / END
                ELSE
                  HWANT
                END
                \->NUM \-> H
                \<<
                  IF SWANT 0 == THEN XMIN ELSE SWANT END \-> START
                  \<<
                    {K} 0. CON \-> FREQ
                    \<<
                      1 N FOR i
                        L i GET \-> V
                        \<<
                          V START - H / FLOOR 1 + \-> IDX
                          \<<
                            IF IDX K > THEN K 'IDX' STO END
                            IF IDX 1 < THEN 1 'IDX' STO END
                            FREQ IDX FREQ IDX GET 1 + PUT 'FREQ' STO
                          \>>
                        \>>
                      NEXT
                      0. 'ACUM' STO
                      0. 'CUMFREQ' STO
                      1 K FOR i
                        START i 1 - H * + \->NUM \-> CLASEINF
                        \<<
                          CLASEINF H + \->NUM \-> CLASESUP
                          \<<
                            FREQ i GET \-> FI
                            \<<
                              CUMFREQ FI + \->NUM 'CUMFREQ' STO
                              FI N / 100. * \->NUM \-> PCT
                              \<<
                                ACUM PCT + \->NUM 'ACUM' STO
                                CLASEINF CLASESUP FI CUMFREQ PCT ACUM
                              \>>
                            \>>
                          \>>
                        \>>
                      NEXT
                      { K 6 } \->ARRY
                      \-> MAT
                      \<<
                        K H START FREQ MAT 5 \->LIST
                      \>>
                      { ACUM CUMFREQ } PURGE
                    \>>
                  \>>
                \>>
              \>>
            \>>
          \>>
        \>>
      \>>
    \>>
  \>>

        START START K H * + XRNG 0 MAXF YRNG
        1 K FOR i
          START i 1 - H * + \-> XLO
          \<<
            XLO H + \-> XHI
            \<<
              XLO 0 R\->C XHI FREQ i GET R\->C BOX
            \>>
          \>>
        NEXT
        'MAXF' PURGE
      \>>

  DBOXPLOTC
  \<<
    @ DBOXPLOTC - nucleo de DBOXPLOT. Los cinco numeros y los outliers.
    @ Uso:  Datos DBOXPLOTC
    @ Deja: n1 = { N MINV Q1 Q2 Q3 MAXV IQR LINF LSUP WMIN WMAX OUTS }
    @         LINF/LSUP = vallas de Tukey (Q1-1.5*RIC y Q3+1.5*RIC),
    @         WMIN/WMAX = extremos de los bigotes (el dato adyacente),
    @         OUTS = lista de valores atipicos.
    @
    @ Cuartiles por INDICE (metodo simplificado), no por la interpolacion
    @ Lp=(p/100)*(n+1) de la catedra: los dos metodos pueden dar valores
    @ distintos. Para el metodo exacto de catedra esta DPCTIL.
    @
    @ WMIN arranca en MAXV y no en MINV: si el minimo de los datos es un
    @ outlier, la comparacion "V < WMIN" tiene que poder disparar igual.
    @ WMAX se apoya en que la lista esta ORDENADA (el ultimo V que no
    @ supera LSUP es el mayor no atipico), por eso no compara.
    @
    @ Sin INFORM ni graficos a proposito: eso lo pone DBOXPLOT.
    IF DUP TYPE 3 == OVER TYPE 29 == OR THEN OBJ\-> 1 GET \->LIST END
    SORT
    \-> L
    \<<
      L SIZE \-> N
      \<<
        L 1 GET \-> MINV
        \<<
          L N GET \-> MAXV
          \<<
            IF N 2 MOD 0 == THEN
              L N 2 / GET L N 2 / 1 + GET + 2 /
            ELSE
              L N 2 / CEIL GET
            END
            \-> Q2
            \<<
              L N 4 / CEIL GET \-> Q1
              \<<
                L N 3 * 4 / CEIL GET \-> Q3
                \<<
                  Q3 Q1 - \-> IQR
                  \<<
                    Q1 1.5 IQR * - \-> LINF
                    \<<
                      Q3 1.5 IQR * + \-> LSUP
                      \<<
                        { } 'OUTS' STO
                        MAXV 'WMIN' STO
                        MAXV 'WMAX' STO
                        1 N FOR i
                          L i GET \-> V
                          \<<
                            IF V LINF < V LSUP > OR THEN
                              OUTS V + 'OUTS' STO
                            END
                            IF V LINF < NOT V WMIN < AND THEN V 'WMIN' STO END
                            IF V LSUP > NOT THEN V 'WMAX' STO END
                          \>>
                        NEXT
                        N MINV Q1 Q2 Q3 MAXV IQR LINF LSUP WMIN WMAX OUTS
                        12 \->LIST
                        { OUTS WMIN WMAX } PURGE
                      \>>
                    \>>
                  \>>
                \>>
              \>>
            \>>
          \>>
        \>>
      \>>

  DINF
  \<<
    @ DINF - captura el infinito REAL del CAS y lo deja en el global
    @ INF, para que DASHO, DESTFUN y DCONT lo usen.
    @
    @ Por que hace falta: el archivo de transferencia tiene que ser
    @ ASCII puro de 7 bits (CLAUDE.md 1), asi que el caracter infinito
    @ no puede viajar dentro del fuente. El escape \.oo parecia la
    @ solucion pero produce un NOMBRE GLOBAL (TYPE 6) que solo se
    @ dibuja como infinito; el de verdad es un ALGEBRAICO (TYPE 9).
    @ Por eso LIMIT sustituia en vez de calcular.
    @
    @ USO: poner el simbolo infinito DEL TECLADO en el nivel 1 de la
    @ pila, y recien ahi correr DINF. Guardar DINF en HOME para que
    @ INF se vea desde cualquier subcarpeta (CLAUDE.md 5).
    @
    @ NO toma el infinito por INFORM a proposito: pasarlo por un campo
    @ de texto obligaria a un STR\-> que lo devolveria como nombre,
    @ que es justo el objeto equivocado. Por la pila llega intacto.
    @
    @ Cajas: TYPE y codigo de caracter del objeto capturado, y una
    @ prueba real de LIMIT. Si esa prueba dice 0, el arreglo funciona.
    @
    @ El codigo se lee del caracter 2, no del 1: \->STR sobre un
    @ algebraico devuelve "'oo'" CON las comillas, asi que el
    @ caracter 1 es el apostrofo (39) y no sirve.
    IF DEPTH 0 ==
    THEN
      "Falta el infinito" 10 CHR +
      "en el nivel 1" +
      MSGBOX
    ELSE
      DUP TYPE \-> TP
      \<<
        DUP 'INF' STO
        \->STR 2 2 SUB NUM \-> COD
        \<<
          "TYPE (debe ser 9): " TP \->STR + 10 CHR +
          "Codigo caracter: " + COD \->STR +
          MSGBOX
          "LIMIT 1/X en INF:" 10 CHR +
          IFERR
            '1/X' 'X' INF = LIMIT EVAL \->STR
          THEN
            "FALLO IGUAL"
          END
          +
          MSGBOX
        \>>
      \>>
    END
