  'DDOMP' STO
  \<<
    @ DCONT - continuidad de una funcion a trozos en el punto de corte.
    @ Cubre entero el punto 2 de la guia (los cuatro incisos).
    @ Cada rama por separado es una funcion comun, asi que alcanza con el
    @ limite ordinario en a; el lateral solo haria falta si la rama misma
    @ revienta ahi, y para eso esta DASV.
    @
    @ NO requiere el global INF: el punto de corte es finito, y el infinito
    @ se detecta por su caracter (ver abajo), no comparando objetos.
    @
    @ Los dos limites quedan tambien en la pila, por si el texto no entra
    @ en la caja.
    "Continuidad en el corte"
    {
      { "Rama izquierda, ej 'X^2':" "'X'" }
      { "Rama derecha, ej '2*X':" "'X'" }
      { "Punto de corte a:" "0" 0 }
    }
    { } { } { }
    INFORM
    IF THEN
      OBJ\-> DROP \-> FI0 FD0 A
      \<<
        FI0 IF DUP TYPE 2 == THEN STR\-> END \-> FI
        \<<
          FD0 IF DUP TYPE 2 == THEN STR\-> END \-> FD
          \<<
            0 0 0 0 \-> LI LD IG ES
            \<<
              IFERR FI 'X' A = LIMIT EVAL THEN "INDEF" END 'LI' STO
              IFERR FD 'X' A = LIMIT EVAL THEN "INDEF" END 'LD' STO
              IFERR LI \->NUM LD \->NUM - ABS .0000001 < THEN LI LD SAME END 'IG' STO
              @ Deteccion del infinito POR EL CARACTER, no por SAME contra INF.
              @ Probado en la maquina: con rama izq '1/X' y corte 0, LIMIT
              @ devuelve +oo (con el signo pegado, que es como la calculadora
              @ lo escribe sola) y el INF guardado por DINF es el oo pelado,
              @ asi que SAME daba falso y el veredicto salia "SALTO FINITO".
              @ El caracter oo tiene codigo 159 (medido con DINF) y aparece
              @ igual en +oo, -oo o 2*oo, asi que POS lo encuentra en todos.
              LI \->STR 159 CHR POS LD \->STR 159 CHR POS + 'ES' STO
              @ Red de seguridad: si el CAS devolvio un numero gigante en vez
              @ del simbolo, tambien es asintota vertical. Todo adentro del
              @ IFERR porque con un simbolico el > puede no dar flag.
              IFERR
                LI \->NUM ABS LD \->NUM ABS MAX 1000000000 >
                IF THEN 1 'ES' STO END
              THEN
              END
              "Lim izq: " LI \->STR + 10 CHR +
              "Lim der: " + LD \->STR +
              MSGBOX
              IF ES 0 >
              THEN
                "ESENCIAL (2a esp.)" 10 CHR +
                "Asint. vert. X=" + A \->STR +
              ELSE
                IF IG
                THEN
                  "LIMITES IGUALES" 10 CHR +
                  "Ver f(a): evitable?" +
                ELSE
                  "SALTO FINITO" 10 CHR +
                  "(1a especie)" +
                END
              END
              MSGBOX
              LI LD
            \>>
          \>>
        \>>
      \>>
    END
  \>>

  'DASV' STO
  \<<
    @ DASHO - asintotas horizontales y oblicuas (TP 8, ej 5 y 6).

    @ NO hace verticales: para eso esta DASV.
    @
    @ REQUIERE el global INF (correr DINF una vez, ver SUITE-MAT1 2).
    @ El infinito NO puede venir del escape \.oo: ese produce un nombre
    @ global (TYPE 6) que solo se dibuja como infinito, y LIMIT termina
    @ sustituyendo en vez de calcular. Confirmado en la maquina.
    @
    @ Deja en la pila n4 = m(+oo), n3 = b(+oo), n2 = m(-oo), n1 = b(-oo).
    IF INF TYPE 9 == NOT
    THEN
      "Falta el global INF" 10 CHR +
      "Correr DINF primero" +
      MSGBOX
    ELSE
      "Asintotas H y oblicuas"
      { { "f(X), ej '(X^2+1)/X':" "'(X^2+1)/X'" } }
      { } { } { }
      INFORM
      IF THEN
        1 GET \-> F0
        \<<
          F0 IF DUP TYPE 2 == THEN STR\-> END \-> F

              IFERR F MP 'X' * - 'X' INF = LIMIT EVAL THEN "INDEF" END 'BP' STO
              IFERR F 'X' / 'X' INF NEG = LIMIT EVAL THEN "INDEF" END 'MN' STO
              IFERR F MN 'X' * - 'X' INF NEG = LIMIT EVAL THEN "INDEF" END 'BN' STO
              "+oo: m=" MP \->STR + 10 CHR +
              "     b=" + BP \->STR +
              MSGBOX
              IFERR
                IF MP \->NUM ABS .0000001 <
                THEN
                  "+oo HORIZONTAL" 10 CHR +
                  "y = " + BP \->STR +
                ELSE
                  "+oo OBLICUA" 10 CHR +
                  "y = " + MP \->STR + "X + " + BP \->STR +
                END
              THEN
                "+oo SIN ASINTOTA" 10 CHR +
                "o el CAS no pudo" +
              END
              MSGBOX
              "-oo: m=" MN \->STR + 10 CHR +
              "     b=" + BN \->STR +
              MSGBOX
              IFERR
                IF MN \->NUM ABS .0000001 <

                  "-oo HORIZONTAL" 10 CHR +

  \<<
    @ DESTFUN - estudio de funcion, hasta donde llegue el CAS.
    @ Cada bloque va en su propio IFERR: si el CAS no puede con uno,
    @ los demas se calculan igual. Un bloque que falla dice por que.
    @ Cubre: derivada y puntos criticos, segunda derivada y candidatos
    @ a inflexion, y asintotas horizontales u oblicuas a los dos lados.
    @ La vertical es opcional y hay que darle el punto candidato: no se
    @ deducen solos (salen de anular denominadores), ver SUITE-MAT1 4.
    @ NO calcula dominio ni imagen: decision tomada, requiere matematica
    @ simbolica fragil y el resultado no seria el dominio real.
    @
    @ REQUIERE el global INF para las asintotas (correr DINF una vez,
    @ ver SUITE-MAT1 2). El escape \.oo no sirve: produce un nombre
    @ global (TYPE 6) y LIMIT termina sustituyendo en vez de calcular.
    @
    @ Deja en la pila n4 = f', n3 = ceros de f', n2 = f'', n1 = ceros de f''.
    IF INF TYPE 9 == NOT
    THEN
      "Falta el global INF" 10 CHR +
      "Correr DINF primero" +
      MSGBOX
    ELSE
      "Estudio de funcion"
      {
        { "f(X):" "'X^3-3*X'" }
        { "Candidato asint. vertical:" "0" 0 }
        { "Probar vertical? 1=si 0=no:" "0" 0 }
      }
      { } { } { }
      INFORM
      IF THEN
        OBJ\-> DROP \-> F0 AV PV
        \<<
          F0 IF DUP TYPE 2 == THEN STR\-> END \-> F
          \<<
            0 0 0 0 \-> D1 Z1 D2 Z2
            \<<
              IFERR F DERVX EXPAND SIMPLIFY THEN "EL CAS NO PUDO" END 'D1' STO
              IFERR D1 'X' ZEROS THEN { } END 'Z1' STO
              IFERR D1 DERVX EXPAND SIMPLIFY THEN "EL CAS NO PUDO" END 'D2' STO
              IFERR D2 'X' ZEROS THEN { } END 'Z2' STO
              "f'(X) =" 10 CHR +
              D1 \->STR +
              MSGBOX
              "Criticos (f'=0):" 10 CHR +
              Z1 \->STR +
              MSGBOX
              "f''(X) =" 10 CHR +
              D2 \->STR +
              MSGBOX
              "Inflexion (f''=0):" 10 CHR +
              Z2 \->STR +
              MSGBOX
              "En +oo:" 10 CHR +
              IFERR
                F 'X' / 'X' INF = LIMIT EVAL \-> M
                \<<
                  IF M \->STR 159 CHR POS 0 >
                  THEN "sin asint. (m infinito)"
                  ELSE
                    IF M \->NUM ABS .0000001 <
                    THEN "HORIZ. y = " F 'X' INF = LIMIT EVAL \->STR +
                    ELSE "OBLICUA m = " M \->STR +
                    END
                  END
                \>>
              THEN
                "sin asintota o el CAS no pudo"
              END
              +
              MSGBOX
              "En -oo:" 10 CHR +
              IFERR
                F 'X' / 'X' INF NEG = LIMIT EVAL \-> M
                \<<
                  IF M \->STR 159 CHR POS 0 >
                  THEN "sin asint. (m infinito)"
                  ELSE
                    IF M \->NUM ABS .0000001 <
                    THEN "HORIZ. y = " F 'X' INF NEG = LIMIT EVAL \->STR +
                    ELSE "OBLICUA m = " M \->STR +
                    END
                  END
                \>>
              THEN
                "sin asintota o el CAS no pudo"
              END
              +
              MSGBOX
              IF PV 1 == THEN
                "En X=" AV \->STR + ":" + 10 CHR +
                IFERR
                  F 'X' AV .000001 - = SUBST EVAL \->NUM ABS 100000 >
                  F 'X' AV .000001 + = SUBST EVAL \->NUM ABS 100000 > OR
                  IF THEN "HAY ASINT. VERTICAL" ELSE "no hay, queda acotada" END
                THEN

  \<<
    @ LHOP - un paso de L'Hopital, con el paso a la vista.
    @ Uso:  'f(X)' 'g(X)' 'X=a' LHOP
    @ Deja: n3 = limite original (confirma que hay indeterminada),
    @       n2 = f'/g' simplificado (esto es lo que se copia a la hoja),
    @       n1 = limite del cociente de derivadas.
    @ No existe comando de L'Hopital en la 50g: LIMIT lo aplica por
    @ dentro pero no muestra el paso, y los finales piden justificarlo.
    @ Solo sirve para 0/0 y oo/oo. Las formas 0*oo y 1^oo hay que
    @ reescribirlas como cociente a mano antes de entrar aca.
    \-> F G PT
    \<<
      IFERR F G / PT LIMIT EVAL THEN "INDEF" END
      F DERVX EVAL G DERVX EVAL / SIMPLIFY \-> Q
      \<<
        Q
        IFERR Q PT LIMIT EVAL THEN "EL CAS NO PUDO" END
      \>>
    \>>
  \>>
  'LHOP' STO
  \<<
    @ DSEP - ecuacion diferencial separable, solucion general.
    @ Uso:  'M(Y)' 'N(X)' DSEP
    @ Deja: n1 = 'F(Y) = G(X) + C'
    @ El programa NO separa la ecuacion: la separacion algebraica es
    @ justo lo que el profesor quiere ver escrito, y automatizarla en
    @ RPL no termina nunca. Entras con M(Y) y N(X) ya separadas y el
    @ programa hace las dos primitivas, cada una en su variable.
    \-> MY NX
    \<<
      IFERR MY 'Y' RISCH EXPAND THEN "NO INTEGRA M(Y)" END
      IFERR NX 'X' RISCH EXPAND THEN "NO INTEGRA N(X)" END
      'C' +
      =
    \>>
  \>>
  'DSEP' STO
  \<<
    @ DSEPI - separable con condicion inicial (problema de valor inicial).
    @ Uso:  'M(Y)' 'N(X)' X0 Y0 DSEPI
    @ Deja: n1 = 'F(Y) = G(X) + K' con la constante ya resuelta.
    @ K = F(Y0) - G(X0), calculada con SUBST. NO usa STO/PURGE sobre
    @ los globales X e Y: ese era el punto mas fragil de la suite,
    @ porque pisaba lo que tuvieras guardado ahi.
    @ Si el CAS no puede evaluar en el punto, deja 'C' simbolica.
    \-> MY NX X0 Y0
    \<<
      0 0 \-> FY GX
      \<<
        IFERR MY 'Y' RISCH EXPAND THEN "NO INTEGRA M(Y)" END 'FY' STO
        IFERR NX 'X' RISCH EXPAND THEN "NO INTEGRA N(X)" END 'GX' STO
        FY
        GX
        IFERR
          FY 'Y' Y0 = SUBST EVAL GX 'X' X0 = SUBST EVAL -
        THEN
          'C'
        END
        +
        =
      \>>
    \>>
  \>>

  \<<
    @ LAGR - multiplicadores de Lagrange, puntos criticos restringidos.
    @ Uso:  'f(X,Y)' 'g(X,Y)' c LAGR
    @ Deja: n2 = el lagrangiano L = f - LM*(g - c),
    @       n1 = solucion del sistema, o un aviso si el CAS no pudo.
    @ Los examenes modelo nunca piden clasificar los puntos, asi que
    @ no arma el hessiano orlado.
    @ Usa LM como multiplicador y DERIV para las parciales (el escape
    @ de derivada parcial no esta confirmado en esta suite).
    @ Purgar X, Y y LM antes de correrlo si tenian valor.
    \-> F G C
    \<<
      F G C - 'LM' * - \-> LG
      \<<
        LG
        IFERR
          LG 'X' DERIV 0 =
          LG 'Y' DERIV 0 =
          LG 'LM' DERIV 0 =
          3 \->LIST { X Y LM } SOLVE
        THEN
          "EL CAS NO RESOLVIO EL SISTEMA: pasarlo a mano"
        END
      \>>
    \>>
  \>>
