  'TF' STO
  \<<
    @ DVFGC - nucleo de DVFG. Verifica que H(X) sea la simplificacion de F/G.
    @ Uso:  'F(X)' 'G(X)' 'H(X)' { puntos } DVFGC
    @ Deja: n1 = { DIF MAL }
    @         DIF = lista de diferencias F/G - H en cada punto,
    @         MAL = cuantos puntos no dieron 0 (o no se pudieron evaluar).
    @
    @ Sin INFORM ni MSGBOX a proposito: la interfaz esta en DVFG.
    @
    @ No demuestra nada, pero dos expresiones distintas casi nunca
    @ coinciden en seis puntos.
    @ Usa el global X y lo purga al terminar.
    \-> F0 G0 H0 P0
    \<<
      DEPTH \-> D0
      \<<
        F0 IF DUP TYPE 2 == THEN STR\-> END \-> F
        \<<
          G0 IF DUP TYPE 2 == THEN STR\-> END \-> G
          \<<
            H0 IF DUP TYPE 2 == THEN STR\-> END \-> H
            \<<
              P0 IF DUP TYPE 2 == THEN STR\-> END \-> PTS
              \<<
                { } 0 \-> DIF MAL
                \<<
                  1 PTS SIZE FOR I
                    PTS I GET 'X' STO
                    IFERR
                      F \->NUM G \->NUM / H \->NUM -
                    THEN
                      "INDEF"
                    END
                    @ Cuenta como "mal" tanto una diferencia no nula como un
                    @ punto que no se pudo evaluar (ahi el valor es el string
                    @ "INDEF", de TYPE 2 y no 0).
                    DUP
                    IF DUP TYPE 0 ==
                    THEN ABS .0000001 >
                    ELSE DROP 1
                    END
                    IF THEN MAL 1 + 'MAL' STO END
                    1 \->LIST DIF SWAP + 'DIF' STO
                  NEXT
                  IFERR { X } PURGE THEN 0 DROP END
                  DIF MAL 2 \->LIST
                  \-> R \<< DEPTH D0 - DROPN R \>>
                \>>
              \>>
            \>>
          \>>
        \>>
      \>>
    \>>
  \>>
  'DVFGC' STO
  \<<
    @ DVFG - verifica que H(X) sea la simplificacion de F(X)/G(X).
    @ Este objeto es SOLO la interfaz: el calculo esta en DVFGC, que toma
    @ 'F' 'G' 'H' { puntos } de la pila y devuelve { DIF MAL }.
    @ Evalua en seis puntos y resta. Todas las diferencias en 0 significa
    @ que el algebra esta bien. No demuestra nada, pero dos expresiones
    @ distintas casi nunca coinciden en seis puntos.
    @ Los puntos por defecto evitan 0, 1 y 4 (las exclusiones del

      { "Puntos de prueba:" "{ -3 -1 .5 2 3 3.5 }" }
    }
    { } { } { }

    IF THEN
      OBJ\-> DROP DVFGC OBJ\-> DROP \-> DIF MAL

        "Puntos probados: " DIF SIZE \->STR + 10 CHR +
        "Con diferencia: " + MAL \->STR +
        MSGBOX
        IF MAL 0 ==
        THEN

          "Todas las dif. en 0" +

      \>>

  'DVFG' STO
  \<<
    @ DDOMPC - nucleo de DDOMP. Sondea el dominio en una lista de puntos.
    @ Uso:  'F(X)' { puntos } DDOMPC
    @ Deja: n1 = { RES DENTRO }
    @         RES = lista con el valor de F en cada punto, o "FUERA",
    @         DENTRO = cuantos puntos pertenecen al dominio.
    @
    @ Sin INFORM ni MSGBOX a proposito: la interfaz esta en DDOMP.
    @
    @ Confirma que puntos pertenecen; NO deduce el dominio.
    @ Requiere modo Complex APAGADO: si no, la raiz de un negativo
    @ devuelve un complejo en vez de error y el punto pasa por bueno.
    @ Usa el global X y lo purga al terminar.
    \-> F0 P0
    \<<
      DEPTH \-> D0
      \<<
        F0 IF DUP TYPE 2 == THEN STR\-> END \-> F
        \<<
          P0 IF DUP TYPE 2 == THEN STR\-> END \-> PTS
          \<<
            { } 0 \-> RES DENTRO
            \<<
              1 PTS SIZE FOR I
                PTS I GET 'X' STO
                IFERR F \->NUM THEN "FUERA" END
                @ Un complejo NO pertenece al dominio REAL. Con el modo
                @ Complex encendido, \v/(-1) no da error: devuelve (0.,1.),
                @ y el punto pasaba por bueno. Medido en el emulador: este
                @ mismo caso contaba 4 puntos en el dominio de \v/X sobre
                @ { -1 0 1 4 } en vez de 3.
                @ Se decide por el TIPO del resultado y no por las banderas:
                @ asi vale con el modo Complex prendido o apagado, sin
                @ depender de que el usuario tenga la maquina como esperamos.
                IF DUP TYPE 0 ==
                THEN DENTRO 1 + 'DENTRO' STO
                ELSE DROP "FUERA"
                END
                1 \->LIST RES SWAP + 'RES' STO
              NEXT
              IFERR { X } PURGE THEN 0 DROP END

              \-> R \<< DEPTH D0 - DROPN R \>>

        \>>
      \>>

  'DDOMP' STO
  \<<
    @ DCONTC - nucleo de DCONT. Continuidad en el punto de corte.
    @ Uso:  'FI(X)' 'FD(X)' A DCONTC
    @ Deja: n1 = { LI LD IG ES }
    @         LI = limite por izquierda, LD = limite por derecha,
    @         IG = 1 si los dos limites coinciden,
    @         ES = mayor que 0 si alguno es infinito (discont. esencial).
    @
    @ Sin INFORM ni MSGBOX A PROPOSITO: eso lo pone DCONT. Separado asi,
    @ el harness puede correr este objeto con argumentos de pila y
    @ comparar el resultado, que con el formulario soldado no se podia.
    @
    @ Limites LATERALES de verdad: la rama izquierda en 'X=a-0' y la
    @ derecha en 'X=a+0'. Antes era el limite ordinario, y con una rama que
    @ revienta en el corte el CAS abria "Unsigned inf. Solve?" y devolvia el
    @ infinito SIN signo: '1/X' por izquierda en 0 daba +oo en vez de -oo.
    @ Medido (harness/casos-lateral.txt): los laterales dan el signo bien.
    @ Se arman como texto y se compilan con STR\->, porque desde la pila
    @ 'X' A 0 - = se reduce a X=a. Igual que DCONTFC.
    @
    @ NO requiere el global INF: el punto de corte es finito, y el
    @ infinito se detecta por su caracter (ver abajo), no comparando.
    \-> FI0 FD0 A
    \<<
      @ Guardian de profundidad (AGENTS.md 2.11): IFERR no limpia la pila,
      @ asi que los argumentos de un comando que fallo quedan apilados.
      @ Se anota la profundidad al entrar y se tira lo que sobre al salir.
      DEPTH \-> D0
      \<<
        FI0 IF DUP TYPE 2 == THEN STR\-> END \-> FI
        \<<
          FD0 IF DUP TYPE 2 == THEN STR\-> END \-> FD
          \<<
            @ a como texto sin tildes, para armar 'X=a-0' y 'X=a+0'
            A \->STR
            IF DUP 1 1 SUB "'" == THEN DUP SIZE 1 - 2 SWAP SUB END
            \-> AS
            \<<
            "'X=" AS + "-0'" + STR\-> "'X=" AS + "+0'" + STR\->
            0 0 0 0 \-> EQI EQD LI LD IG ES
            \<<
              IFERR FI EQI LIMIT EVAL THEN "INDEF" END 'LI' STO
              IFERR FD EQD LIMIT EVAL THEN "INDEF" END 'LD' STO
              IFERR LI \->NUM LD \->NUM - ABS .0000001 < THEN LI LD SAME END 'IG' STO
              @ Deteccion del infinito POR EL CARACTER, no por SAME contra INF.
              @ Probado en la maquina: con rama izq '1/X' y corte 0, LIMIT
              @ devuelve +oo (con el signo pegado, que es como la calculadora
              @ lo escribe sola) y el INF guardado por DINF es el oo pelado,
              @ asi que SAME daba falso y el veredicto salia "SALTO FINITO".
              @ El caracter oo tiene codigo 159 y aparece igual en +oo, -oo
              @ o 2*oo, asi que POS lo encuentra en todos.
              LI \->STR 159 CHR POS LD \->STR 159 CHR POS + 'ES' STO
              @ Red de seguridad: si el CAS devolvio un numero gigante en vez
              @ del simbolo, tambien es asintota vertical.
              @ Solo actua si la deteccion por caracter NO encontro nada. Antes
              @ pisaba ES siempre, y con eso tapaba si el detector primario habia
              @ funcionado: el harness veia ES=1 (de esta red) tanto cuando el
              @ caracter estaba como cuando no. Ahora el VALOR de ES dice quien lo
              @ detecto: 3 = por el caracter oo, 1 = por el tamano del numero.
              IF ES 0 ==
              THEN
                IFERR
                  LI \->NUM ABS LD \->NUM ABS MAX 1000000000 >
                  IF THEN 1 'ES' STO END
                THEN
                END
              END
              LI LD IG ES 4 \->LIST
              \-> R \<< DEPTH D0 - DROPN R \>>
            \>>
            \>>
          \>>
        \>>
      \>>
    \>>
  \>>

  'DCONT' STO
  \<<
    @ DCONTFC - nucleo de DCONTF. Continuidad de UNA funcion (no a trozos)
    @ en un punto a: las tres condiciones del TP 9 y la clasificacion de
    @ la catedra (evitable si el limite existe, inevitable si no).
    @ Uso:  'F(X)' A DCONTFC
    @ Deja: n1 = { FA LI LD K }
    @         FA = f(a), o "NO EXISTE"
    @         LI, LD = limites laterales, o "NO EXISTE"; con ~ adelante
    @                  si salieron del sondeo numerico y no del CAS
    @         K = veredicto: 0 continua, 1 evitable (no existe f(a)),
    @             2 evitable (f(a) distinto del lim), 3 salto finito,
    @             4 lim infinito, 5 lateral no existe,
    @             6 continua de un solo lado (a es borde del dominio)
    @
    @ Sin INFORM ni MSGBOX A PROPOSITO: eso lo pone DCONTF, asi el harness
    @ puede probar este objeto por pila.
    @
    @ Medido antes de escribir esto (harness/casos-lateral.txt, emulador
    @ con ROM de 50g, 14 de 20 con los 6 restantes explicados):
    @  - 'X=a-0' y 'X=a+0' son limites laterales de verdad: ABS(X)/X en
    @    0 da -1 y 1, y 1/X da -oo y +oo CON signo.
    @  - Armada desde numeros de la pila no sirve ('X' 0 0 - = da X=0),
    @    pero compilada desde texto con STR\-> si. Por eso se arma como
    @    texto.
    @  - El CAS ignora el dominio: \v/X en 0-0 da 0. Un lateral fuera del
    @    dominio se detecta con el sondeo numerico en a -/+ 1e-6, que ahi
    @    devuelve un complejo (AGENTS.md 2.14: decidir por TYPE).
    @  - f(a) fuera del dominio NO da error: 0/0 da '?', 1/0 da 'oo' (y
    @    9.99999999999E499 con \->NUM). Se decide por el caracter 159,
    @    por el "?" y por la magnitud, no con IFERR.
    @  - 'SIN(1/X)' en 0+0 da '?': lateral que no existe.
    @
    @ Cada IFERR lleva su guardian de profundidad (AGENTS.md 2.11): los
    @ laterales se acumulan en la pila y un argumento que quedara de un
    @ comando fallido correria todo.
    \-> F0 A
    \<<
      DEPTH \-> D0
      \<<
        F0 IF DUP TYPE 2 == THEN STR\-> END \-> F
        \<<
          @ a como texto sin tildes, para armar 'X=a-0'
          A \->STR
          IF DUP 1 1 SUB "'" == THEN DUP SIZE 1 - 2 SWAP SUB END
          \-> AS
          \<<
            @ Un paso por lado: S=-1 izquierda, S=1 derecha.
            @ Cada paso deja 3 valores: lo que se muestra, el valor, y
            @ el codigo 0 finito, 1 infinito, 2 no existe.
            -1 1 FOR S
              "'X=" AS + IF S 0 < THEN "-0'" ELSE "+0'" END + STR\->
              \-> EQ
              \<<
                DEPTH \-> D1
                \<<
                  IFERR F 'X' A S .000001 * + = SUBST EVAL \->NUM THEN "ERR" END
                  \-> P0 \<< DEPTH D1 - DROPN P0 \>>
                \>>
                DEPTH \-> D1
                \<<
                  IFERR F EQ LIMIT EVAL THEN "ERR" END
                  \-> L0 \<< DEPTH D1 - DROPN L0 \>>
                \>>
                \-> P L
                \<<
                  "NO EXISTE" 0 3 \-> D N K
                  \<<
                    @ Fuera del dominio de ese lado: el sondeo no da un real.
                    IF P TYPE 0 == NOT THEN 2 'K' STO END
                    IF K 3 == L TYPE 2 == NOT AND
                    THEN
                      IF L \->STR 159 CHR POS
                      THEN L 'D' STO 1 'K' STO
                      ELSE
                        IF L \->STR "?" POS
                        THEN 2 'K' STO
                        ELSE
                          DEPTH \-> D1
                          \<<
                            IFERR L \->NUM THEN "ERR" END
                            \-> V0 \<< DEPTH D1 - DROPN V0 \>>
                          \>>
                          IF DUP TYPE 0 ==
                          THEN 'N' STO L 'D' STO 0 'K' STO
                          ELSE DROP
                          END
                        END
                      END
                    END
                    @ El CAS no resolvio: vale el sondeo, marcado con ~
                    IF K 3 ==
                    THEN
                      IF P ABS 100000 >
                      THEN
                        1 'K' STO
                        "~" IF P 0 < THEN "-" ELSE "+" END + "inf" + 'D' STO
                      ELSE
                        0 'K' STO P 'N' STO "~" P 6 RND \->STR + 'D' STO
                      END
                    END
                    D N K
                  \>>
                \>>
              \>>
            2 STEP
            \-> LI LIN LIK LD LDN LDK
            \<<
              @ Condicion 1: f(a).
              DEPTH \-> D1
              \<<
                IFERR F 'X' A = SUBST EVAL THEN "ERR" END
                \-> V0 \<< DEPTH D1 - DROPN V0 \>>
              \>>
              \-> V
              \<<
                "NO EXISTE" 0 0 \-> FA FAN FAE
                \<<
                  IF V TYPE 2 == NOT
                  THEN
                    IF V \->STR 159 CHR POS V \->STR "?" POS + NOT
                    THEN
                      DEPTH \-> D1
                      \<<
                        IFERR V \->NUM THEN "ERR" END
                        \-> V1 \<< DEPTH D1 - DROPN V1 \>>
                      \>>
                      IF DUP TYPE 0 ==
                      THEN
                        IF DUP ABS 1.E400 <
                        THEN 'FAN' STO V 'FA' STO 1 'FAE' STO
                        ELSE DROP
                        END
                      ELSE DROP
                      END
                    END
                  END
                  @ Condicion 2: el limite existe si los laterales son finitos
                  @ e iguales. Condicion 3: coincide con f(a).
                  IF LIK 0 == LDK 0 == AND
                  THEN LIN LDN - ABS LIN ABS 1 + .000001 * <
                  ELSE 0
                  END
                  \-> EQL
                  \<<
                    IF EQL
                    THEN
                      IF FAE
                      THEN
                        IF FAN LIN - ABS LIN ABS 1 + .000001 * <
                        THEN 0 ELSE 2 END
                      ELSE 1
                      END
                    ELSE
                      IF LIK 1 == LDK 1 == OR
                      THEN 4
                      ELSE
                        IF LIK 2 == LDK 2 == OR
                        THEN
                          @ Borde del dominio: un lado no existe y el otro
                          @ coincide con f(a), ej '\v/X' en 0.
                          0
                          IF FAE
                          THEN
                            IF LIK 0 == THEN FAN LIN - ABS LIN ABS 1 + .000001 * < OR END
                            IF LDK 0 == THEN FAN LDN - ABS LDN ABS 1 + .000001 * < OR END
                          END
                          IF THEN 6 ELSE 5 END
                        ELSE 3
                        END
                      END
                    END
                    \-> K
                    \<<
                      FA LI LD K 4 \->LIST
                      \-> R \<< DEPTH D0 - DROPN R \>>
                    \>>
                  \>>
                \>>
              \>>
            \>>
          \>>
        \>>
      \>>
    \>>
  \>>
  'DCONTFC' STO
  \<<
    @ DCONTF - continuidad de UNA funcion (no a trozos) en un punto a.
    @ Para funciones a trozos esta DCONT. Cubre el TP 9 (ej. 2 y 3).
    @
    @ Este objeto es SOLO la interfaz: formulario y cajas. La matematica
    @ esta en DCONTFC, que toma 'F' A de la pila y devuelve
    @ { FA LI LD K }. Separados para que el harness pueda probar el
    @ calculo sin tipear en un INFORM.
    @
    @ Deja en la pila: n3 = f(a), n2 = lim izq, n1 = lim der.
    "Continuidad de f"
    {
      { "f(X), ej '1/X':" "'1/X'" }
      { "Punto a:" "1" 0 }
    }
    { } { } { }
    INFORM
    IF THEN
      OBJ\-> DROP \-> F A
      \<<
        F A DCONTFC OBJ\-> DROP \-> FA LI LD K
        \<<
          @ Un string se muestra tal cual; lo demas con \->STR.
          FA IF DUP TYPE 2 == NOT THEN \->STR END
          LI IF DUP TYPE 2 == NOT THEN \->STR END
          LD IF DUP TYPE 2 == NOT THEN \->STR END
          \-> SFA SLI SLD
          \<<
            "f(a) = " SFA + 10 CHR +
            "Lim izq: " + SLI +
            MSGBOX
            "Lim der: " SLD +
            MSGBOX
            CASE
              K 0 == THEN "CONTINUA" 10 CHR + "f(a) = lim" + END
              K 1 == THEN "EVITABLE (no f(a))" 10 CHR + "Redefinir f(a)=" + SLI + END
              K 2 == THEN "EVITABLE f(a)<>lim" 10 CHR + "Redefinir f(a)=" + SLI + END
              K 3 == THEN "INEVITABLE (esencial)" 10 CHR + "salto finito (1a esp)" + END
              K 4 == THEN "INEVITABLE (esencial)" 10 CHR + "lim infinito (2a esp)" + END
              K 5 == THEN "INEVITABLE (esencial)" 10 CHR + "lim lateral no existe" + END
              "CONTINUA de 1 lado" 10 CHR + "a: borde del dominio" +
            END
            MSGBOX
            FA LI LD
          \>>
        \>>
      \>>
    END
  \>>

                            IF ASIM NOT
                            THEN 1 'ASIM' STO P 'CP' STO A 'CFP' STO B 'CFM' STO
                            END
                          ELSE
                            IF A TYPE 0 ==
                            THEN
                              NDEF 1 + 'NDEF' STO
                              A ABS 1 + .000000001 * \-> TOL
                              \<<
                                IF B A - ABS TOL > OKP AND
                                THEN
                                  0 'OKP' STO
                                  @ Si ya hay un punto de dominio asimetrico,
                                  @ ese es el contraejemplo que se muestra.
                                  IF ASIM NOT
                                  THEN P 'CP' STO A 'CFP' STO B 'CFM' STO
                                  END
                                END
                                IF B A + ABS TOL > OKI AND
                                THEN 0 'OKI' STO P 'CIP' STO A 'CIFP' STO B 'CIFM' STO
                                END
                              \>>
                            END
                          END
                        \>>
                      \>>
                    NEXT
                    DROP
                    CASE
                      ASIM
                      THEN 0 "NI PAR NI IMPAR: dominio no simetrico" CP CFP CFM FMX
                      END
                      NDEF 0 ==
                      THEN 2 "No pude evaluar f en los puntos" 0 0 0 FMX
                      END
                      OKP OKI AND
                      THEN 3 "PAR e IMPAR: f = 0" 0 0 0 FMX
                      END
                      OKP
                      THEN 1 "PAR: f(-X) = f(X)" 0 0 0 FMX
                      END
                      OKI
                      THEN -1 "IMPAR: f(-X) = -f(X)" 0 0 0 FMX
                      END
                      @ Ni par ni impar: el contraejemplo de la paridad.
                      0 "NI PAR NI IMPAR" CP CFP CFM FMX
                    END
                  \>>
                \>>
              END
              6 \->LIST
              IF PF PG OR
              THEN
                DUP 2 GET " (verificado con representantes)" +
                2 SWAP PUT
              END
            \>>
          \>>
          FL STOF
        \>>
        \-> R \<< DEPTH D0 - DROPN R \>>
      \>>
    \>>
  \>>
  'DPARC' STO
  \<<
    @ DPAR - paridad de una funcion. Dos usos:
    @  - f concreta: dejar F y G en 0. Ej '4*X+1/X'.
    @  - el ejercicio teorico "si F es par y G impar, que es F(G(X))+X^3?":
    @    escribir la expresion con F y G, y poner 1 (par) o -1 (impar) en
    @    cada una. Se verifica con funciones representantes.
    @
    @ Este objeto es SOLO la interfaz. La matematica esta en DPARC, que
    @ toma 'EXPR' PF PG de la pila y devuelve { K MSG P FP FMP FMX }.
    @
    @ Deja en la pila: n2 = f(-X), n1 = el veredicto.
    "Paridad"
    {
      { "f(X), ej '4*X+1/X':" "'4*X+1/X'" }
      { "F: 1 par, -1 impar:" "0 si no hay F" 0 }
      { "G: 1 par, -1 impar:" "0 si no hay G" 0 }
    }
    { } { } { }
    INFORM
    IF THEN
      OBJ\-> DROP \-> E PF PG
      \<<
        @ Un campo numerico nunca visitado vuelve vacio: vale 0.
        PF IF DUP TYPE 0 == NOT THEN DROP 0 END
        PG IF DUP TYPE 0 == NOT THEN DROP 0 END
        \-> QF QG
        \<<
          E QF QG DPARC OBJ\-> DROP \-> K MSG P FP FMP FMX
          \<<
            "f(-X) =" 10 CHR + FMX \->STR + MSGBOX
            MSG MSGBOX
            IF K 0 ==
            THEN
              "Contraejemplo x=" P \->STR + 10 CHR +
              "f(x)=" + FP \->STR + "  f(-x)=" + FMP \->STR +
              MSGBOX
            END
            FMX MSG
          \>>
        \>>
      \>>
    END

  'DPAR' STO
  \<<
    @ DASVTC - nucleo de DASVT. Asintotas verticales de f(X), SIN que el
    @ usuario pase el candidato: los busca solo.
    @ Uso:  'f(X)' DASVTC
    @ Deja: n1 = { AV CAND MSG }
    @         AV   = los candidatos que SI son asintota, exactos como los
    @                da DDOMC (ej { -3 } o { '-\v/2' '\v/2' })
    @         CAND = todos los candidatos probados (los PES de DDOMC)
    @         MSG  = "" o avisos: los de DDOMC, y los de cada candidato
    @                que no se pudo decidir o donde las dos pruebas no
    @                coinciden
    @
    @ Sin INFORM ni MSGBOX a proposito: la interfaz esta en DASVT.
    @
    @ Candidatos: los puntos criticos de DDOMC (ceros de denominadores,
    @ bordes de LN y de raices). DDOMC no simplifica, asi que el 3 de
    @ (X-3)/(X^2-9) entra como candidato y se descarta despues por el
    @ limite, que es lo que la catedra quiere ver: evitable, no asintota.
    @ Un polo que DCONDC no ve (una funcion que no reconoce) no se busca.
    @
    @ Quien decide: DCONTFC, veredicto K=4 (algun lateral infinito).
    @ Usa los laterales del CAS 'X=a-0' / 'X=a+0', e ignora el lado que
    @ queda fuera del dominio (ahi el sondeo da complejo, AGENTS.md 2.14).
    @ Por que no DASVC solo: sondea en a +/- 1e-6 con umbral 1e5, y eso
    @ no alcanza para una singularidad lenta. LN(X) en 0+1e-6 da -13.8, y
    @ 1/\v/(X-1) en 1+1e-6 da 1000: DASVC diria SIN ASINTOTA en los dos.
    @ Y al reves: 1000000*(X-3)/(X^2-9) en 3 da 166667, y DASVC diria
    @ ASINTOTA donde el limite es finito.
    @
    @ Para que sirve DASVC aca: de control, y de respaldo.
    @  - Si DCONTFC fallo entero (K=-1), decide el sondeo, con aviso.
    @  - Si el sondeo no se pudo evaluar (HAY=-1) y el CAS no vio
    @    asintota, se avisa.
    @  - Si el sondeo da un valor grande pero el CAS da limite finito, se
    @    avisa: no se agrega, pero no se calla.
    @ "Grande" exige un valor REAL de magnitud > 1e5. Un complejo no
    @ cuenta aunque su modulo sea enorme: es el lado de afuera del
    @ dominio (borde cerrado, ej \v/(X-1) en 1), y el HAY de DASVC mira
    @ ABS sin mirar el TYPE. Con \v/(X-1) no muerde (modulo 1e-3), pero
    @ asi no depende de eso.
    @
    @ Cada llamada lleva su IFERR con guardian de profundidad (AGENTS.md
    @ 2.11), y el FOR va envuelto en IF porque CAND puede venir vacio
    @ (f polinomio) y el FOR corre una vez igual (AGENTS.md 2.7).
    \-> F0
    \<<
      DEPTH \-> D0
      \<<
        F0 IF DUP TYPE 2 == THEN STR\-> END \-> F
        \<<
          DEPTH \-> D1
          \<<
            IFERR F 0 DDOMC THEN "ERR" END
            \-> R0 \<< DEPTH D1 - DROPN R0 \>>
          \>>
          \-> DR
          \<<
            IF DR TYPE 5 ==
            THEN DR 3 GET DR 4 GET
            ELSE { } "No se pudo calcular el dominio. "
            END
            { }
            \-> PES MSG AV
            \<<
              IF PES SIZE 0 >
              THEN
                1 PES SIZE
                FOR I
                  PES I GET \-> A
                  \<<
                    @ a como texto sin tildes, para los avisos
                    A \->STR
                    IF DUP 1 1 SUB "'" == THEN DUP SIZE 1 - 2 SWAP SUB END
                    \-> AS
                    \<<
                      @ El CAS: A exacto, asi el lateral se arma con el
                      @ valor exacto (ej 'X=\v/2-0').
                      DEPTH \-> D1
                      \<<
                        IFERR F A DCONTFC 4 GET THEN -1 END
                        \-> K0 \<< DEPTH D1 - DROPN K0 \>>
                      \>>
                      @ El sondeo: DASVC necesita un numero.
                      DEPTH \-> D1
                      \<<
                        IFERR F A \->NUM DASVC THEN { 0 0 -1 } END
                        \-> S0 \<< DEPTH D1 - DROPN S0 \>>
                      \>>
                      OBJ\-> DROP
                      \-> K VI VD HAY
                      \<<
                        0
                        IF VI TYPE 0 == THEN VI ABS 100000 > OR END
                        IF VD TYPE 0 == THEN VD ABS 100000 > OR END
                        \-> G
                        \<<
                          CASE
                            K 4 ==
                            THEN AV A + 'AV' STO
                            END
                            K -1 ==
                            THEN
                              IF G
                              THEN
                                AV A + 'AV' STO
                                MSG "X=" + AS + ": decidido solo por sondeo. " + 'MSG' STO
                              ELSE
                                MSG "X=" + AS + ": no se pudo decidir. " + 'MSG' STO
                              END
                            END
                            IF HAY -1 ==
                            THEN
                              MSG "X=" + AS + ": el sondeo no se pudo evaluar. " + 'MSG' STO
                            END
                            IF G
                            THEN
                              MSG "X=" + AS + ": valores grandes, pero limite finito. " + 'MSG' STO
                            END
                          END
                        \>>
                      \>>
                    \>>
                  \>>
                NEXT
              END
              AV PES MSG 3 \->LIST
            \>>
          \>>
        \>>
        \-> R \<< DEPTH D0 - DROPN R \>>
      \>>
    \>>
  \>>
  'DASVTC' STO
  \<<
    @ DASVT - asintotas verticales de f(X), buscando los candidatos solo.
    @ Este objeto es SOLO la interfaz: el calculo esta en DASVTC, que toma
    @ 'f(X)' de la pila y devuelve { AV CAND MSG }.
    @ Los candidatos salen del dominio (DDOMC): ceros de denominadores y
    @ bordes de LN y raices. Cada uno se decide por limites laterales.
    @ Para mirar UN punto con los dos valores sondeados, esta DASV.
    @ Escribir f SIN SIMPLIFICAR: (X-3)/(X^2-9) muestra que el 3 es
    @ candidato y NO es asintota (discontinuidad evitable).
    @ Deja en la pila: n1 = la lista de asintotas, exactas.
    "Asintotas verticales"
    {
      { "f(X), ej '1/(X^2-9)':" "'1/(X^2-9)'" }
    }
    { } { '1/(X^2-9)' } { '1/(X^2-9)' }
    INFORM
    IF THEN
      OBJ\-> DROP \-> F0
      \<<
        F0 DASVTC OBJ\-> DROP \-> AV CAND MSG
        \<<
          @ Las listas como texto: X=-3, X=3
          ""
          IF AV SIZE 0 >
          THEN
            1 AV SIZE
            FOR I
              IF I 1 > THEN ", " + END
              "X=" + AV I GET \->STR
              IF DUP 1 1 SUB "'" == THEN DUP SIZE 1 - 2 SWAP SUB END
              +
            NEXT
          END
          ""
          IF CAND SIZE 0 >
          THEN
            1 CAND SIZE
            FOR I
              IF I 1 > THEN ", " + END
              CAND I GET \->STR
              IF DUP 1 1 SUB "'" == THEN DUP SIZE 1 - 2 SWAP SUB END
              +
            NEXT
          END
          \-> TAV TC
          \<<
            IF CAND SIZE 0 ==
            THEN "Sin candidatos:" 10 CHR + "f no tiene polos" +
            ELSE "Candidatos:" 10 CHR + TC +
            END
            MSGBOX
            IF AV SIZE 0 ==
            THEN "SIN ASINTOTAS" 10 CHR + "verticales" +
            ELSE "Asintota vertical:" 10 CHR + TAV +
            END
            MSGBOX
            IF MSG SIZE THEN MSG MSGBOX END
            AV
          \>>
        \>>
      \>>
    END

  'DASVT' STO
  \<<
    @ DCEROC - nucleo de DCERO. Ceros de H(X) QUE PERTENECEN AL DOMINIO,
    @ sacados de la expresion TAL COMO SE ESCRIBIO (sin SIMPLIFY).
    @ Uso:  'H(X)' DCEROC        (H puede llegar como string)
    @ Deja: n1 = { CZ ZD TD MSG }
    @         CZ  = ceros reales dentro del dominio, exactos y ordenados
    @         ZD  = candidatos que se DESCARTARON por caer fuera del
    @               dominio, exactos y ordenados. Es lo que la catedra
    @               quiere ver: en (X^2-9)/(X-3) el numerador se anula en
    @               3 y en -3, pero 3 no esta en el dominio.
    @         TD  = el dominio como texto (DDOMC), ej "R - {3}"
    @         MSG = "" o avisos: el CAS no resuelve, periodica, el
    @               dominio (avisos de DDOMC), o "NO CONFIABLE" si el
    @               control falla
    @
    @ Como:
    @  1. Candidatos. ZEROS sobre H sola no alcanza: el CAS simplifica
    @     por dentro y (X^2-9)/(X-3) le da -3, sin el 3 que hay que
    @     descartar. Por eso se recorre el arbol desde arriba (OBJ\->,
    @     AGENTS.md 2.20, igual que DCONDC) y se buscan los ceros de cada
    @     FACTOR: de un cociente el numerador, de un producto los dos
    @     factores, de un NEG o una raiz su argumento (\v/g = 0 <=> g = 0).
    @     Lo demas (una suma, un LN, una potencia) es un factor entero y va
    @     a ZEROS tal cual. Si hubo que descomponer, H misma tambien va a
    @     ZEROS, pero sin avisar si falla: los factores ya la cubren.
    @  2. ZEROS con una sola raiz no da lista (2.19): se normaliza. Las
    @     raices complejas se ignoran, decidido por TYPE tras \->NUM
    @     (2.14). Repetidos (|a-b| < 1E-9) se cuentan una vez.
    @  3. Cada candidato se prueba contra las condiciones de dominio del
    @     arbol sin simplificar (DCONDC + DSATC): adentro va a CZ, afuera
    @     a ZD.
    @  4. Control, como el sondeo de DINTC: H evaluada en cada cero
    @     aceptado tiene que dar |H| < 1E-9. Si no, "NO CONFIABLE".
    @
    @ Modo Complex apagado adentro (-103 CF, RCLF/STOF, 2.20): con el
    @ prendido ZEROS devuelve basura compleja sin error.
    \-> H0
    \<<
      RCLF \-> FL
      \<<
        -103 CF
        DEPTH \-> D0
        \<<
          H0 IF DUP TYPE 2 == THEN STR\-> END \-> H
          \<<
            H DCONDC \-> CL
            \<<
              { } 0 { } { } "" \-> LV FD PE PN MSG
              \<<
                @ ---- 1. factores: la pila es la pila de trabajo, con
                @ { } como centinela abajo (el recorrido de DCONDC). FD = 1
                @ si se descompuso algo.
                { } H
                DO
                  CASE
                    DUP TYPE 9 ==
                    THEN
                      DUP OBJ\-> \->STR \-> N FS
                      \<<
                        @ En la pila: H' y sus N argumentos arriba.
                        CASE
                          FS "/" ==
                          THEN DROP SWAP DROP 1 'FD' STO
                          END
                          FS "*" ==
                          THEN ROT DROP 1 'FD' STO
                          END
                          FS "NEG" == FS "-" == N 1 == AND OR FS 131 CHR == OR
                          THEN SWAP DROP 1 'FD' STO
                          END
                          N DROPN 1 \->LIST LV SWAP + 'LV' STO
                        END
                      \>>
                    END
                    DUP TYPE 6 ==
                    THEN 1 \->LIST LV SWAP + 'LV' STO
                    END
                    @ Un numero suelto no tiene ceros: se descarta.
                    DROP
                  END
                UNTIL DUP TYPE 5 ==
                END
                DROP
                @ Lista de { G SIL }: SIL = 1 no avisa si ZEROS falla.
                { }
                IF FD THEN H 1 2 \->LIST 1 \->LIST + END
                IF LV SIZE 0 >
                THEN
                  1 LV SIZE
                  FOR I
                    LV I GET 0 2 \->LIST 1 \->LIST +
                  NEXT
                END
                \-> TL
                \<<
                  @ ---- 2. candidatos: ZEROS de cada uno ----
                  IF TL SIZE 0 >
                  THEN
                    1 TL SIZE
                    FOR I
                      TL I GET OBJ\-> DROP \-> G SIL
                      \<<
                        DEPTH \-> D1
                        \<<
                          IFERR G 'X' ZEROS THEN "ERR" END
                          \-> Z0 \<< DEPTH D1 - DROPN Z0 \>>
                        \>>
                        \-> Z
                        \<<
                          IF Z TYPE 2 ==
                          THEN
                            IF SIL NOT
                            THEN MSG "El CAS no resuelve " + G \->STR + "=0. " + 'MSG' STO
                            END
                          ELSE
                            Z IF DUP TYPE 5 == NOT THEN 1 \->LIST END
                            \-> ZL
                            \<<
                              IF ZL SIZE 0 >
                              THEN
                                1 ZL SIZE
                                FOR J
                                  ZL J GET \-> Z1
                                  \<<
                                    DEPTH \-> D1
                                    \<<
                                      IFERR Z1 \->NUM THEN "ERR" END
                                      \-> N0 \<< DEPTH D1 - DROPN N0 \>>
                                    \>>
                                    \-> ZN
                                    \<<
                                      IF ZN TYPE 0 ==
                                      THEN
                                        0 \-> DUPL
                                        \<<
                                          IF PN SIZE 0 >
                                          THEN
                                            1 PN SIZE
                                            FOR K
                                              IF PN K GET ZN - ABS .000000001 <
                                              THEN 1 'DUPL' STO
                                              END
                                            NEXT
                                          END
                                          IF DUPL NOT
                                          THEN PE Z1 + 'PE' STO PN ZN + 'PN' STO
                                          END
                                        \>>
                                      ELSE
                                        @ Un complejo es una raiz no real: se
                                        @ ignora. Un n1 es una familia periodica.
                                        IF Z1 \->STR "n1" POS SIL NOT AND
                                        THEN MSG "Periodica: no soportado. " + 'MSG' STO
                                        END
                                      END
                                    \>>
                                  \>>
                                NEXT
                              END
                            \>>
                          END
                        \>>
                      \>>
                    NEXT
                  END
                  @ ---- 3. ordenar y separar: dentro o fuera del dominio ----
                  PN SORT \-> PS
                  \<<
                    { } { } \-> CZ ZD
                    \<<
                      IF PS SIZE 0 >
                      THEN
                        1 PS SIZE
                        FOR K
                          PE PN PS K GET POS GET \-> Z1
                          \<<
                            IF CL Z1 DSATC
                            THEN
                              CZ Z1 + 'CZ' STO
                              @ ---- 4. control: H(Z1) tiene que dar 0 ----
                              DEPTH \-> D1
                              \<<
                                IFERR H 'X' Z1 = SUBST EVAL \->NUM THEN "ERR" END
                                \-> V0 \<< DEPTH D1 - DROPN V0 \>>
                              \>>
                              \-> V
                              \<<
                                IF V TYPE 0 ==
                                THEN V ABS .000000001 <
                                ELSE 0
                                END
                                IF NOT
                                THEN
                                  Z1 \->STR
                                  IF DUP 1 1 SUB "'" == THEN DUP SIZE 1 - 2 SWAP SUB END
                                  MSG "NO CONFIABLE: H(" + SWAP + ") no da 0. " + 'MSG' STO
                                END
                              \>>
                            ELSE ZD Z1 + 'ZD' STO
                            END
                          \>>
                        NEXT
                      END
                      @ ---- el dominio, como texto (DDOMC, dominio natural) ----
                      H 0 DDOMC DUP 1 GET SWAP 4 GET \-> TD DMSG
                      \<<
                        IF DMSG SIZE
                        THEN MSG "Dominio: " + DMSG + 'MSG' STO
                        END
                        CZ ZD TD MSG 4 \->LIST
                      \>>
                    \>>
                  \>>
                \>>
              \>>
            \>>
          \>>
          \-> R \<< DEPTH D0 - DROPN R \>>
        \>>
        FL STOF
      \>>
    \>>

  'DCEROC' STO
  \<<
    @ DCERO - ceros de una funcion QUE PERTENECEN AL DOMINIO. El
    @ ejercicio tipico de parcial: ceros de f/g o de g o f, descartando
    @ los que caen fuera del dominio.
    @

    @ toma 'H' de la pila y devuelve { CZ ZD TD MSG }.
    @

    @ H se arma SIN simplificar, a proposito: F G / y SUBST de 'X', sin
    @ EVAL ni SIMPLIFY. DOPFUNC compone con SUBST EVAL SIMPLIFY, y eso
    @ cancela (X^2-9)/(X-3) a X+3 y borra el 3 del dominio (el bug de
    @ domain49). Aca el dominio sale de la expresion escrita.
    @
    @ Los campos traen valores iniciales (el ejemplo de la cancelacion):
    @ un campo nunca visitado sin valor inicial llega como NOVAL.
    @
    @ Deja en la pila: n2 = H, la expresion analizada; n1 = CZ, los ceros.
    "Ceros en el dominio"
    {
      { "f(X):" "Sin simplificar, ej '(X^2-9)'" }
      { "g(X):" "Solo para oper. 1, 2 y 3" }
      { "Oper. 0=f 1=f/g 2=fog 3=gof:" "0 = ceros de f sola" 0 }
    }
    { } { 'X^2-9' 'X-3' 1 } { 'X^2-9' 'X-3' 1 }
    INFORM
    IF THEN
      OBJ\-> DROP \-> F0 G0 OP
      \<<
        F0 IF DUP TYPE 2 == THEN STR\-> END
        G0 IF DUP TYPE 2 == THEN STR\-> END
        \-> F G
        \<<
          CASE
            OP 1 == THEN F G / "(f/g)(X)" END
            OP 2 == THEN F 'X' G = SUBST "(fog)(X)" END
            OP 3 == THEN G 'X' F = SUBST "(gof)(X)" END
            F "f(X)"
          END
          \-> H NOM
          \<<
            H DCEROC OBJ\-> DROP \-> CZ ZD TD MSG
            \<<
              NOM " =" + 10 CHR + H \->STR + MSGBOX
              "Dom =" 10 CHR + TD + MSGBOX
              "Ceros en el dominio:" 10 CHR + CZ \->STR + MSGBOX
              @ Los descartados son lo que la catedra pide ver escrito:
              @ anulan el numerador pero no estan en el dominio.
              IF ZD SIZE
              THEN
                "Descartados, fuera del" 10 CHR +
                "dominio: " + ZD \->STR +
                MSGBOX
              END
              IF MSG SIZE THEN MSG MSGBOX END
              H CZ
            \>>
          \>>
        \>>
      \>>
    END
