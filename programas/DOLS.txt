%%HP: T(3)A(R)F(.);
\<<
  @ DOLS - regresion lineal por sumatorias.
  @ Interfaz: el calculo esta en DOLSC, que devuelve { N B0 B1 R R2 }.
  @ Pide dos listas separadas (X e Y), no una matriz: el indexado de
  @ matrices con M { i j } GET resulto mas fragil.
  @ B0 y B1 se redondean con SIGFIG a 4 cifras significativas para
  @ mostrar, si no salen cosas como "5.8013220973E-5".
  @ SIGFIG tiene que ser visible: dentro del paquete LAB.txt lo es,
  @ porque todos los objetos viven en el mismo DIR. Si falta, el
  @ nombre 'SIGFIG' queda SIN EVALUAR en la pila y el resultado sale
  @ mal sin avisar.
  "Regresion OLS [X Y]"
  {
    { "Datos X:" "Vector [x] o Lista {x}" }
    { "Datos Y:" "Vector [y] o Lista {y}" }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP DOLSC OBJ\-> DROP \-> N B0 B1 R R2
    \<<
      "Y = " B0 4 SIGFIG \->STR + " + " + B1 4 SIGFIG \->STR + "*X" +
      MSGBOX
      "r: " R \->STR + 10 CHR +
      "R2: " + R2 \->STR +
      MSGBOX
    \>>
  END
\>>
