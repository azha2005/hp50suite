%%HP: T(3)A(R)F(.);
\<<
  @ DMODA - moda(s) de un conjunto de datos.
  @ Interfaz: el calculo esta en DMODAC, que devuelve { MODES MAXFREQ }.
  @ Frecuencia maxima 1 significa que todos los valores son distintos:
  @ no hay moda.
  "Moda"
  { { "Datos:" "Vector [x] o Lista {x}" } }
  { } { } { }
  INFORM
  IF THEN
    1 GET DMODAC OBJ\-> DROP \-> MODES MAXFREQ
    \<<
      IF MAXFREQ 1 == THEN
        "Sin moda: todos los valores son distintos entre si."
        MSGBOX
      ELSE
        "Moda(s): " MODES \->STR + 10 CHR +
        "Frecuencia: " + MAXFREQ \->STR +
        MSGBOX
      END
    \>>
  END
\>>
