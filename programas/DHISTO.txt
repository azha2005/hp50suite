%%HP: T(3)A(R)F(.);
\<<
  @ DHISTO - histograma de barras.
  @ Tres capas: DFRECTABLAC calcula las clases, DHISTOG dibuja, y este
  @ objeto pone el formulario, el PICTURE y las cajas. PICTURE es
  @ interactivo, asi que tiene que quedar aca y no en el dibujo: de otro
  @ modo el harness no puede probar el grafico.
  @ El binning NO se calcula aca ni se repite: es el mismo de la tabla
  @ de frecuencias. La tabla y el grafico del mismo ejercicio no pueden
  @ dar clases distintas.
  @
  @ Campos K/Ancho/Inicio opcionales: algunos ejemplos de catedra (ej.
  @ horas trabajadas por semana) NO usan Sturges ni el minimo real como
  @ punto de partida -- el profesor elige K a mano y arranca los
  @ intervalos en un entero comodo MENOR al minimo real (ej. 10 en vez
  @ de 12) para que el eje se lea mejor. Con 0 se calcula automatico.
  "Histograma Sturges"
  {
    { "Datos:" "Vector [x] o Lista {x}" }
    { "K deseado (0=Sturges):" "0" 0 }
    { "Ancho deseado (0=auto):" "0" 0 }
    { "Inicio deseado (0=Min real):" "0" 0 }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP \-> DATA0 KWANT HWANT SWANT
    \<<
      DATA0 KWANT HWANT SWANT DFRECTABLAC OBJ\-> DROP
      DROP \-> K H START FREQ
      \<<
        K H START FREQ DHISTOG
        PICT PICTURE
        DATA0
        IF DUP TYPE 3 == OVER TYPE 29 == OR THEN OBJ\-> 1 GET \->LIST END
        SIZE \-> N
        \<<
          "Inicio: " START \->STR + 10 CHR +
          "Ancho (H): " + H \->STR +
          MSGBOX
          "Clases (K): " K \->STR + 10 CHR +
          "N datos: " + N \->STR +
          MSGBOX
          "Frecuencias:" 10 CHR +
          FREQ \->STR +
          MSGBOX
        \>>
      \>>
    \>>
  END
\>>
