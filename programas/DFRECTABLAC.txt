%%HP: T(3)A(R)F(.);
\<<
  @ DFRECTABLAC - nucleo de DFRECTABLA. Tabla de frecuencias.
  @ Uso:  Datos K H Inicio DFRECTABLAC     (K/H/Inicio en 0 = automatico)
  @ Deja: n1 = { K H START FREQ MAT }
  @         FREQ = vector de frecuencias absolutas por clase,
  @         MAT  = matriz K x 6: Inicio, Fin, Abs, Acum.Abs, %, Acum.%
  @ Automatico = la regla de la catedra (diapositiva de Cicowiez,
  @ "Calcular el tamanio del intervalo", con el ejemplo Big Mac):
  @   K0 = Sturges, 1 + 3.322*log(N), redondeado        (6.49 -> 6)
  @   Ancho = R/K0 redondeado HACIA ARRIBA a 1 cifra significativa
  @           (0.9067 -> 1, 4.2 -> 5)
  @   Inicio = el multiplo del ancho justo debajo del minimo (1.62 -> 1)
  @   K = las clases que hagan falta para cubrir hasta el maximo
  @ Con BMHIST da las 7 clases 1-2, 2-3 ... 7-8 de la diapositiva, y
  @ con HORAS da K=5, Ancho=5, Inicio=10, que es el enunciado de catedra.
  @ Si K se fija a mano se respeta; si con el inicio redondeado no llega
  @ a cubrir el maximo, arranca en el minimo.
  @ Las clases son [a, b): cerradas a izquierda ("1.00 - 1.99"), y la
  @ ultima tambien toma el borde derecho.
  @ Sin INFORM ni MSGBOX a proposito: la interfaz esta en DFRECTABLA.
  @
  @ El bucle de filas deja los 6 valores de cada fila en la pila sin
  @ consumirlos: ahi se acumulan las K*6 celdas hasta el \->ARRY final.
  @ Por eso este nucleo NO lleva guardian de profundidad (AGENTS.md
  @ 2.11): la acumulacion en la pila es intencional, no basura.
  \-> DATA0 KWANT HWANT SWANT
  \<<
    DATA0
    IF DUP TYPE 3 == OVER TYPE 29 == OR THEN OBJ\-> 1 GET \->LIST END
    SORT
    \-> L
    \<<
      L SIZE \-> N
      \<<
        L 1 GET \-> XMIN
        \<<
          L N GET \-> XMAX
          \<<
            IF KWANT 0 == THEN
              1 3.322 N LOG * + 0 RND
            ELSE
              KWANT
            END
            \->NUM \-> K0
            \<<
              IF HWANT 0 == THEN
                IF XMAX XMIN == THEN
                  1
                ELSE
                  XMAX XMIN - K0 / \->NUM \-> H0
                  \<<
                    H0 LOG FLOOR ALOG \-> E
                    \<<
                      H0 E / CEIL E *
                    \>>
                  \>>
                END
              ELSE
                HWANT
              END
              \->NUM \-> H
              \<<
                IF SWANT 0 == THEN
                  XMIN H / FLOOR H * \->NUM \-> SF
                  \<<
                    IF KWANT 0 == SF K0 H * + XMAX < NOT OR
                    THEN SF ELSE XMIN END
                  \>>
                ELSE
                  SWANT
                END
                \->NUM \-> START
                \<<
                  IF KWANT 0 == THEN
                    XMAX START - H / FLOOR 1 +
                  ELSE
                    K0
                  END
                  \->NUM \-> K
                  \<<
                  {K} 0. CON \-> FREQ
                  \<<
                    1 N FOR i
                      L i GET \-> V
                      \<<
                        V START - H / FLOOR 1 + \-> IDX
                        \<<
                          IF IDX K > THEN K 'IDX' STO END
                          IF IDX 1 < THEN 1 'IDX' STO END
                          FREQ IDX FREQ IDX GET 1 + PUT 'FREQ' STO
                        \>>
                      \>>
                    NEXT
                    0. 'ACUM' STO
                    0. 'CUMFREQ' STO
                    1 K FOR i
                      START i 1 - H * + \->NUM \-> CLASEINF
                      \<<
                        CLASEINF H + \->NUM \-> CLASESUP
                        \<<
                          FREQ i GET \-> FI
                          \<<
                            CUMFREQ FI + \->NUM 'CUMFREQ' STO
                            FI N / 100. * \->NUM \-> PCT
                            \<<
                              ACUM PCT + \->NUM 'ACUM' STO
                              CLASEINF CLASESUP FI CUMFREQ PCT ACUM
                            \>>
                          \>>
                        \>>
                      \>>
                    NEXT
                    { K 6 } \->ARRY
                    \-> MAT
                    \<<
                      K H START FREQ MAT 5 \->LIST
                    \>>
                    { ACUM CUMFREQ } PURGE
                  \>>
                  \>>
                \>>
              \>>
            \>>
          \>>
        \>>
      \>>
    \>>
  \>>
\>>
