\<<
  @ DSTATS - media, varianza, desvio y CV.
  @ Interfaz: el calculo esta en DSTATSC, que toma los datos de la pila
  @ y devuelve { N XBAR VARZ DESV CV }.
  @ Se parte en 3 cajas de 2 lineas sin encabezado decorativo: 6 lineas
  @ en una sola caja se cortan y se pierde el CV (MSGBOX no hace scroll).
  "Media, Varianza, Desvio, CV"
  { { "Datos:" "Vector [x] o Lista {x}" } }
  { } { } { }
  INFORM
  IF THEN
    1 GET DSTATSC OBJ\-> DROP \-> N XBAR VARZ DESV CV
    \<<
      "N: " N \->STR + 10 CHR +
      "Media: " + XBAR \->STR +
      MSGBOX
      "Var: " VARZ \->STR + 10 CHR +
      "Desvio: " + DESV \->STR +
      MSGBOX
      "CV: " CV \->STR + " %" +
      MSGBOX
    \>>
  END
\>>
