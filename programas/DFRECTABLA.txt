%%HP: T(3)A(R)F(.);
\<<
  @ DFRECTABLA - tabla de frecuencias como MATRIZ.
  @ Interfaz: el calculo esta en DFRECTABLAC, que devuelve
  @ { K H START FREQ MAT }. La matriz queda en la pila.
  @ K/Ancho/Inicio en 0 = automatico, regla de catedra (ver DFRECTABLAC). Se pueden fijar a
  @ mano para reproducir ejercicios que eligen K arbitrariamente.
  @ En modo algebraico, EDIT sobre la matriz abre un editor de celdas
  @ tipo planilla; en RPN solo edita la matriz plana.
  "Tabla de Frecuencias"
  {
    { "Datos:" "Vector [x] o Lista {x}" }
    { "K (0=auto):" "0" 0 }
    { "Ancho (0=auto):" "0" 0 }
    { "Inicio (0=auto):" "0" 0 }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP DFRECTABLAC OBJ\-> DROP \-> K H START FREQ MAT
    \<<
      "K: " K \->STR + 10 CHR +
      "Ancho: " + H \->STR +
      MSGBOX
      "Inicio: " START \->STR + 10 CHR +
      "Tabla en la pila" +
      MSGBOX
      MAT
    \>>
  END
\>>
