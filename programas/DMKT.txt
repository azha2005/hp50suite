%%HP: T(3)A(R)F(.);
\<<
  @ DMKT - equilibrio de mercado simple, con grafico.
  @ Interfaz: el calculo esta en DMKTC, que toma a b c d T de la pila y
  @ devuelve { PE QE }. Aca quedan el formulario y el dibujo.
  @ Van dos INFORM seguidos porque el limite practico es ~4 campos por
  @ pantalla (con 5 el ultimo queda inalcanzable con las flechas).
  "Mercado: Qd=a-b*P, Qs=c+d*P"
  {
    { "a (Demanda Auto):" "0" 0 }
    { "b (Sensib. Dem):" "0" 0 }
    { "c (Oferta Auto):" "0" 0 }
    { "d (Sensib. Of):" "0" 0 }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP \-> A B C D
    \<<
      "Impuesto (T)"
      { { "Impuesto T (0=sin imp):" "0" 0 } }
      { } { } { }
      INFORM
      IF THEN
        1 GET \-> T
        \<<
          A B C D T DMKTC OBJ\-> DROP \-> PE QE
          \<<
            @ Grafico de Oferta y Demanda.
            @ Eje horizontal = Precio (P), de 0 a PMAX = 2*PE (centra el
            @ equilibrio). Eje vertical = Cantidad (Q), de 0 a QMAX, el
            @ mayor entre el intercepto de demanda (A) y la oferta en
            @ PMAX, para que ninguna curva se salga de la pantalla.
            PE 2. * \->NUM \-> PMAX
            \<<
              C D PMAX * + \->NUM \-> SMAX
              \<<
                IF A SMAX > THEN A ELSE SMAX END \->NUM \-> QMAX
                \<<
                  ERASE
                  0 130 XRNG 0 79 YRNG
                  
                  @ Ejes de referencia
                  20. 60. R\->C 110. 60. R\->C LINE
                  20. 10. R\->C 20. 60. R\->C LINE
                  
                  @ Demanda: (P=0,Q=A) a (P=PMAX,Q=A-B*PMAX)
                  A QMAX / 50. * 60. SWAP - 0 RND \-> DPY1
                  \<<
                    A B PMAX * - QMAX / 50. * 60. SWAP - 0 RND \-> DPY2
                    \<<
                      20. DPY1 R\->C 110. DPY2 R\->C LINE
                      
                      @ Oferta: (P=0,Q=C) a (P=PMAX,Q=SMAX)
                      C QMAX / 50. * 60. SWAP - 0 RND \-> SPY1
                      \<<
                        SMAX QMAX / 50. * 60. SWAP - 0 RND \-> SPY2
                        \<<
                          20. SPY1 R\->C 110. SPY2 R\->C LINE
                          
                          @ Punto de equilibrio (cruz +)
                          PE PMAX / 90. * 20. + 0 RND \-> EPX
                          \<<
                            QE QMAX / 50. * 60. SWAP - 0 RND \-> EPY
                            \<<
                              EPX 3 - EPY R\->C EPX 3 + EPY R\->C LINE
                              EPX EPY 3 - R\->C EPX EPY 3 + R\->C LINE
                              
                              PICT PICTURE
                              
                              "Precio (P*): " PE \->STR + 10 CHR +
                              "Cantidad (Q*): " + QE \->STR +
                              MSGBOX
                            \>>
                          \>>
                        \>>
                      \>>
                    \>>
                  \>>
                \>>
              \>>
            \>>
          \>>
        \>>
      END
    \>>
  END
\>>
