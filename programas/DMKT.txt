%%HP: T(3)A(R)F(.);
\<<
  @ DMKT - equilibrio de mercado simple, con grafico.
  @ Tres capas: DMKTC calcula { PE QE }, DMKTG dibuja, y este objeto
  @ pone los formularios, el PICTURE y la caja. PICTURE es interactivo,
  @ asi que queda aca: de otro modo el harness no puede probar el
  @ grafico.
  @ Van dos INFORM seguidos porque el limite practico es ~4 campos por
  @ pantalla (con 5 el ultimo queda inalcanzable con las flechas).
  "Mercado: Qd=a-b*P, Qs=c+d*P"
  {
    { "a (Demanda Auto):" "0" 0 }
    { "b (Sensib. Dem):" "0" 0 }
    { "c (Oferta Auto):" "0" 0 }
    { "d (Sensib. Of):" "0" 0 }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP \-> A B C D
    \<<
      "Impuesto (T)"
      { { "Impuesto T (0=sin imp):" "0" 0 } }
      { } { } { }
      INFORM
      IF THEN
        1 GET \-> T
        \<<
          A B C D T DMKTC \-> RES
          \<<
            A B C D RES DMKTG
            PICT PICTURE
            "Precio (P*): " RES 1 GET \->STR + 10 CHR +
            "Cantidad (Q*): " + RES 2 GET \->STR +
            MSGBOX
            RES 1 GET RES 2 GET
          \>>
        \>>
      END
    \>>
  END
\>>
