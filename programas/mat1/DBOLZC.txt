%%HP: T(3)A(R)F(.);
\<<
  @ DBOLZC - nucleo de DBOLZ. Teorema de Bolzano (valor intermedio):
  @ si f es continua en [a,b] y f(a) y f(b) tienen signo distinto,
  @ existe al menos un c en (a,b) con f(c) = 0.
  @ Uso:  'f(X)' a b DBOLZC
  @ Deja: n1 = { FA FB HAY RAIZ MSG }
  @   FA, FB = f(a) y f(b)
  @   HAY    = 1 si el teorema garantiza una raiz, 0 si no la garantiza
  @   RAIZ   = la raiz localizada por biseccion, o el extremo si ya es raiz
  @   MSG    = que se puede afirmar y que no
  @
  @ HAY = 0 NO significa que no haya raiz: Bolzano es condicion
  @ suficiente, no necesaria. X^2-1 en [-2,2] tiene DOS raices y f(a) y
  @ f(b) son las dos positivas. El mensaje lo dice con todas las letras,
  @ porque confundir eso es el error tipico del ejercicio.
  @
  @ La raiz sale por BISECCION, 40 pasos, que es el metodo que el propio
  @ teorema sugiere, y no por ZEROS: asi el numero que sale es el del
  @ razonamiento y no el de un comando que hace otra cosa por adentro.
  @ Sin INFORM ni MSGBOX a proposito: la interfaz esta en DBOLZ.
  \-> F0 A0 B0
  \<<
    DEPTH \-> D0
    \<<
      F0 IF DUP TYPE 2 == THEN STR\-> END
      A0 \->NUM B0 \->NUM
      \-> F AA BB
      \<<
        IF AA BB >
        THEN BB AA
        ELSE AA BB
        END
        \-> A B
        \<<
          IFERR F 'X' A = SUBST EVAL \->NUM THEN 1000000000000 END
          IF DUP TYPE 0 == NOT THEN DROP 1000000000000 END
          IFERR F 'X' B = SUBST EVAL \->NUM THEN 1000000000000 END
          IF DUP TYPE 0 == NOT THEN DROP 1000000000000 END
          \-> FA FB
          \<<
            CASE FA 0 ==
              THEN FA FB 1 A "f(a)=0: el extremo a YA es raiz" 5 \->LIST END
            FB 0 ==
              THEN FA FB 1 B "f(b)=0: el extremo b YA es raiz" 5 \->LIST END
            FA FB * 0 <
              THEN
                A B FA \-> P Q FP
                \<<
                  1 40 FOR k
                    P Q + 2 /
                    \-> M
                    \<<
                      IFERR F 'X' M = SUBST EVAL \->NUM THEN 0 END
                      IF DUP TYPE 0 == NOT THEN DROP 0 END
                      \-> FM
                      \<<
                        IF FM FP * 0 <
                        THEN M 'Q' STO
                        ELSE M 'P' STO FM 'FP' STO
                        END
                      \>>
                    \>>
                  NEXT
                  FA FB 1 P Q + 2 / "HAY AL MENOS UNA RAIZ EN (a,b)" 5 \->LIST
                \>>
              END
            @ Ojo con el conteo: esta rama apilaba 4 valores y hacia
            @ 5 \->LIST, asi que se llevaba puesto lo que hubiera debajo
            @ en la pila. Faltaba el lugar de RAIZ. Lo encontro el caso
            @ bolz-nohay, que pedia el elemento 3 y daba ERROR mientras
            @ el 5 contestaba bien: la lista salia corrida una posicion.
            FA FB 0 "SIN LOCALIZAR" "NO SE PUEDE AFIRMAR: f(a) y f(b) tienen igual signo. OJO: eso NO prueba que no haya raiz" 5 \->LIST
            END
            \-> R \<< DEPTH D0 - DROPN R \>>
          \>>
        \>>
      \>>
    \>>
  \>>
\>>
