%%HP: T(3)A(R)F(.);
\<<
  @ DDOMP - sondea el dominio de F(X) en una lista de puntos.
  @ Este objeto es SOLO la interfaz: el calculo esta en DDOMPC, que toma
  @ 'F(X)' { puntos } de la pila y devuelve { RES DENTRO }.
  @ Confirma que puntos pertenecen; NO deduce el dominio.
  @ Un resultado complejo cuenta como FUERA, asi que ya NO hace falta
  @ tener apagado el modo Complex: lo decide DDOMPC por el tipo.
  @ La lista de resultados (valor o "FUERA") queda en la pila.
  "Sondear dominio"
  {
    { "F(X), ej '\v/X':" "'\v/X'" }
    { "Puntos a probar:" "{ -2 -1 0 1 2 4 }" }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP DDOMPC OBJ\-> DROP \-> RES DENTRO
    \<<
      "Puntos probados: " RES SIZE \->STR + 10 CHR +
      "En el dominio: " + DENTRO \->STR +
      MSGBOX
      "Detalle en la pila" 10 CHR +
      "(valor o FUERA)" +
      MSGBOX
      RES
    \>>
  END
\>>
