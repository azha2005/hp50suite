%%HP: T(3)A(R)F(.);
\<<
  @ DASHO - asintotas horizontales y oblicuas (TP 8, ej 5 y 6).
  @ Este objeto es SOLO la interfaz: el calculo esta en DASHOC, que toma
  @ 'f(X)' de la pila y devuelve { MP BP MN BN TP TN }.
  @ NO hace verticales: para eso esta DASV.
  @
  @ REQUIERE el global INF (correr DINF una vez, ver SUITE-MAT1 2).
  @
  @ Deja en la pila n4 = m(+oo), n3 = b(+oo), n2 = m(-oo), n1 = b(-oo).
  IF INF TYPE 9 == NOT
  THEN
    "Falta el global INF" 10 CHR +
    "Correr DINF primero" +
    MSGBOX
  ELSE
    "Asintotas H y oblicuas"
    { { "f(X), ej '(X^2+1)/X':" "'(X^2+1)/X'" } }
    { } { } { }
    INFORM
    IF THEN
      1 GET DASHOC OBJ\-> DROP \-> MP BP MN BN TP TN
      \<<
        "+oo: m=" MP \->STR + 10 CHR +
        "     b=" + BP \->STR +
        MSGBOX
        "+oo: " TP +
        MSGBOX
        "-oo: m=" MN \->STR + 10 CHR +
        "     b=" + BN \->STR +
        MSGBOX
        "-oo: " TN +
        MSGBOX
        MP BP MN BN
      \>>
    END
  END
\>>
