%%HP: T(3)A(R)F(.);
\<<
  @ LHOP - un paso de L'Hopital, con el paso a la vista.
  @ Interfaz: el calculo esta en LHOPC, que toma 'f' 'g' 'X=a' de la pila
  @ y devuelve { L0 Q L1 }.
  @ Para el punto en el infinito se escribe 'X=INF' (correr DINF antes).
  @ El cociente de derivadas queda tambien en la pila: casi nunca entra
  @ en una caja de 2 lineas y es lo que hay que copiar a la hoja.
  "Un paso de L'Hopital"
  {
    { "f(X) (numerador):" "'SIN(X)'" }
    { "g(X) (denominador):" "'X'" }
    { "Punto, ej 'X=0' o 'X=INF':" "'X=0'" }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP LHOPC OBJ\-> DROP \-> L0 Q L1
    \<<
      "Limite original:" 10 CHR +
      L0 \->STR +
      MSGBOX
      "f'/g' =" 10 CHR +
      Q \->STR +
      MSGBOX
      "Limite de f'/g':" 10 CHR +
      L1 \->STR +
      MSGBOX
      L0 Q L1
    \>>
  END
\>>
