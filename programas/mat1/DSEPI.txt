%%HP: T(3)A(R)F(.);
\<<
  @ DSEPI - separable con condicion inicial (problema de valor inicial).
  @ Interfaz: el calculo esta en DSEPIC, que toma 'M(Y)' 'N(X)' X0 Y0 de
  @ la pila y devuelve { FY GX K SOL }.
  @ Entras con la ecuacion YA separada. La constante sale resuelta con la
  @ condicion y(X0) = Y0.
  @ La solucion queda tambien en la pila.
  "PVI separable: M(Y)dy = N(X)dx"
  {
    { "M(Y), ej 'Y':" "'Y'" }
    { "N(X), ej 'X':" "'X'" }
    { "X0:" "0" 0 }
    { "Y0 = y(X0):" "1" 0 }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP DSEPIC OBJ\-> DROP \-> FY GX K SOL
    \<<
      "Integral M(Y): " FY \->STR + 10 CHR +
      "Integral N(X): " + GX \->STR +
      MSGBOX
      "Constante K:" 10 CHR +
      K \->STR +
      MSGBOX
      "Solucion particular:" 10 CHR +
      SOL \->STR +
      MSGBOX
      SOL
    \>>
  END
\>>
