\<<
  @ DSEP - ecuacion diferencial separable, solucion general.
  @ Interfaz: el calculo esta en DSEPC, que toma 'M(Y)' 'N(X)' de la pila
  @ y devuelve { FY GX SOL }.
  @ Entras con la ecuacion YA separada: M(Y) dy = N(X) dx. La separacion
  @ algebraica es justo lo que el profesor quiere ver escrito a mano.
  @ La solucion queda tambien en la pila.
  "EDO separable: M(Y)dy = N(X)dx"
  {
    { "M(Y), ej 'Y':" "'Y'" }
    { "N(X), ej 'X':" "'X'" }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP DSEPC OBJ\-> DROP \-> FY GX SOL
    \<<
      "Integral de M(Y):" 10 CHR +
      FY \->STR +
      MSGBOX
      "Integral de N(X):" 10 CHR +
      GX \->STR +
      MSGBOX
      "Solucion general:" 10 CHR +
      SOL \->STR +
      MSGBOX
      SOL
    \>>
  END
\>>
