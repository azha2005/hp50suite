\<<
  @ DTCAMBIO - tasa de crecimiento anual compuesta (CAGR).
  @ Interfaz: el calculo esta en DTCAMBIOC, que devuelve { RC }.
  "Tasa Anual Compuesta"
  {
    { "Var Total Acum (%):" "" 0 }
    { "Anio Inicial (T1):" "" 0 }
    { "Anio Final (T2):" "" 0 }
  }
  { } { } { }
  INFORM
  IF THEN
    OBJ\-> DROP DTCAMBIOC 1 GET \-> RC
    \<<
      "Tasa Anual Compuesta:" 10 CHR +
      RC \->STR + " % anual" +
      MSGBOX
    \>>
  END
\>>
